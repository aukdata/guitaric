# Guitaric

ギターの音をマイクで聞き取り、TAB譜どおりに弾けているかを判定する練習アプリです。コード名と構成音を表示する解析ツールも入っています。

**https://aukdata.github.io/guitaric/**

ブラウザだけで動き、インストールや登録は不要です（PWA としてホーム画面に追加することもできます）。PC とスマートフォンの両方に対応しています。

## 機能

### 曲

- **曲の一覧**: 自分で作った曲とプリセット（王道進行、カノン進行、Aマイナーペンタのリフなど）が並びます。曲はブラウザ（localStorage）に保存されます。
- **練習**: TAB譜を見ながら弾くと、マイクで音を判定し、正しく弾けたら次の音・コードへ進みます。
  - コードは1回ごとのピッキング（ストローク）を検出し、余計な音や足りない音があると不合格になります
  - お手本の再生、クリック（4分・8分）、再生速度（0.2〜1.5倍）、音量を設定できます
- **編集**: DTM 風の TAB エディタで、1音ずつ、またはコード名で打ち込めます。
  - ハンマリング・プリング・スライド・チョーキング（full / 1/2）・チョーキングを戻す・ビブラート・ハーモニクス・ブリッジミュート・ブラッシング・休符・タイ・音の長さ
  - 小節ごとのテンポ・繰り返し（回数・1番カッコ）は TAB の小節の上の帯をタップして設定、カポ
  - 再生（選択位置から）、クリック、速さの調整
  - 元に戻す / やり直す、コピー・貼り付け、キーボードショートカット（`?` で一覧）
  - テキストでもまとめて入力できます（下記）
- **書き出し / 読み込み**: 曲を `.guitaric.json` ファイルに書き出したり、ファイル（JSON またはテキスト）から読み込んだりできます。

### 解析

- マイクの音から、鳴っているコード名とその候補、構成音（低い順）、最も強い音のチューナー表示、12音名ごとの強さ（クロマ）を表示します
- 録音して WAV ファイルとして保存できます

## テキストでの書き方

| 書き方 | 意味 |
| --- | --- |
| `C G Am F` | 1小節に1コード。`Bb` `F#m` `C7` `Gmaj7` `Dsus4` なども使えます |
| `\| C G \| Am F \|` | 縦棒で小節を区切ると、1小節に複数のコードを入れられます |
| `C/G` | スラッシュコード（ベースを G に） |
| `C*4` | 1小節の中で C を4回弾く |
| `6-3` | 6弦3フレット（1 = 細い弦 〜 6 = 太い弦） |
| `6-3+5-2` | 同時に弾く音 |
| `r` | 休符 |
| `4-7h` `4-5p` `5-5s` | ハンマリング・プリング・スライド |
| `3-7b` `3-7b1` `3-7d` | 1音チョーキング・半音チョーキング・チョーキングを戻す |
| `3-7v` | ビブラート |
| `3-<12>` | ハーモニクス（3・4・5・7・9・12・16・19・24フレット） |
| `6-0_` `E5_` | ブリッジミュート（P.M.） |
| `x` | ブラッシング |
| `~:8` | タイ（直前の音を8マス分のばす） |
| `6-3:2` | 長さ（1マスの2つ分。1マスは標準で8分音符） |
| `@cell16` | 先頭に書くと1マスが16分音符になる |
| `# …` | `#` で始まる行はコメント（エディタで編集しても残る） |
| `@capo3` | 先頭に書くとカポ3フレット |
| `@bpm120` | ここからテンポ120（曲の途中にも書ける。曲ごとのBPM設定はなく、テンポはこれで決める） |
| `@[ … @]` `@]3` | 間を2回（`@]3` なら3回）繰り返す。`@[` がなければ曲の頭から、`@]` がなければ次の `@[` の前か曲の最後まで |
| `@[ A @1 B @2 C @]` | カッコ: `@n` から次のカッコか `@]` までを n 回目だけ弾く（A B A C） |
| `C?` `6-3?` | 判定ゆるめ（弾けば何の音でも進む） |

例: `5-3 4-0 4-2 4-3 3-0 3-2 2-0 2-1`（C メジャースケール）

## 使うときの注意

- マイクを使うため、Chrome / Edge / Safari などのブラウザで直接開いてください。Claude アプリ内のプレビューなど、埋め込み表示ではマイクが使えません。
- 初めてマイクを開始するときに、ブラウザがマイクの使用許可を求めます。
- 判定の精度はマイクや周りの音に左右されます。お手本やクリックの音はできるだけイヤホンで聞くと誤判定が減ります。

## ローカルで動かす

ビルドは不要です。リポジトリを取得して `index.html` を PC の Chrome / Edge で開けば動きます（`file://` でもマイクが使えます）。スマートフォンから使う場合は HTTPS が必要なので、GitHub Pages などで公開してください。

```
git clone https://github.com/aukdata/guitaric.git
```

## 構成

素の HTML / CSS / JavaScript（ライブラリなし、Web Audio API）で書かれています。

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面全体 |
| `css/style.css` | スタイル（ライト / ダークテーマ） |
| `js/app.js` | タブの切り替え |
| `js/core.js` | 音の解析（多重音高推定、コード推定、ピッキング検出） |
| `js/analyze.js` | 解析タブ（表示と録音） |
| `js/songs.js` | コード辞書、テキストの読み取り、プリセット、保存 |
| `js/editor.js` | 曲の一覧 |
| `js/tabedit.js` | TAB エディタ |
| `js/tab.js` | TAB譜の描画（SVG） |
| `js/practice.js` | 練習画面と判定 |
| `js/player.js` | お手本の再生 |
| `js/metronome.js` | クリック |
| `js/songfile.js` | 曲ファイルの書き出し・読み込み |
| `js/icons.js` | アイコン（Lucide） |
| `sw.js` `manifest.webmanifest` | PWA（オフライン対応） |

`main` ブランチが GitHub Pages に公開されます。
