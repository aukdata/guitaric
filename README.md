# Guitaric

ギターの音を聞いて、TAB譜どおりに弾けているかを判定する練習アプリ（作成中）。

- 練習: TAB譜を見ながら弾き、正しく弾けたら次へ進む（ウェイトモード）。リズムモードは作成中
- 曲を作る: `C G Am F` のようなコード進行や `6-3 5-2` のような1音ずつのTABを打ち込み、ブラウザに保存する
- 解析: ギターの音から構成音とコードを推定する

ブラウザだけで動きます。マイクを使うため、HTTPS で公開したページ（GitHub Pages）か、PC でローカルの `index.html` を Chrome / Edge で開いて使ってください。
