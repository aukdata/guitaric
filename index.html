書き方

コード

  • C G Am F … 1小節に1コード
  • C Cm C7 Cm7 Cmaj7 C6 Cm6 C5 Csus2 Csus4 C7sus4 Cadd9 Cdim Cdim7 Caug Cm7-5 … 種類（根音は C# Db なども可）
  • C/G … スラッシュコード（ベースを G に）
  • C*4 … 1小節でCを4回弾く（コードが変わる直前の1回は判定ゆるめ）

単音

  • 6-3 … 6弦3フレット（1＝細い弦 〜 6＝太い弦）
  • 6-3+5-2 … 同時に弾く音
  • 5-3+4-x+3-0 … x はミュートした弦（音は出さない）
  • r … 休符
  • ~ … タイ（直前の音をのばす）
  • x … ブラッシング

小節と長さ

  • | C G | Am F | … 縦棒で小節を区切る（1小節に複数入れられる）
  • :2 … マス数で長さを指定（6-3:2 r:4 ~:8 C*2:4）。1マス＝8分音符

弦ごとの奏法（フレットのすぐ後ろ。順番は自由、各グループから1つずつ）

  • 入り方：4-7h 4-5p … ハンマリング・プリング。5-5s … スライド（前の音から）。5-7i … スライドイン
  • 音程の動き：3-7b 3-7b1 … 1音・半音チョーキング。3-7d 3-7d1 3-7d2 … チョーキングを戻す（半音・1音）。5-7o … スライドアウト。3-5t7 … トリル（7フレットと往復）
  • 3-7v … ビブラート
  • 3-7b! 5-7s! … スライド・チョーキングを速く
  • 3-7bv 4-5hb 5-12s+3-14s … 組み合わせ・同時に弾く音の例
  • 3-<12> … ハーモニクス（3・4・5・7・9・12・16・19・24フレット）

音符ごとの記号（音符の最後。順番は自由）

  • 6-0_ E5_ … ブリッジミュート
  • 6-3. … スタッカート（長さはそのまま、音を短く切る）
  • 5-5' 5-7h … 装飾音（長さを持たず、次の音の頭で一瞬鳴る）
  • C? 6-3? … 判定ゆるめ（弾けば何の音でも進む）
  • 4-0+3-2_.?:2 … 組み合わせの例

テンポと繰り返し

  • @bpm120 … ここからテンポ120（曲の途中にも書ける）
  • @[ … @] … 間を2回繰り返す。@]3 で3回。@] がなければ次の @[ か最後まで
  • @alt1 @alt2 … 1番・2番カッコ（@[ A @alt1 B @alt2 C @] は A B A C）。@alt0 でカッコを閉じる

最初の音より前に書く設定（順番は自由）

  • @cell16 … 1マスを16分音符に（@cell4 @cell8 @cell32 も可）
  • @capo3 … カポ3フレット（フレットはカポから数える）

コメント

  • % … … % から行の終わりまで
